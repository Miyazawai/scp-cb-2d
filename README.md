# SCP:CB 2D

把《SCP – Containment Breach》的体验做成**像素俯视 2D** 的免费同人游戏。开源、非商业、可离线运行。

![title](docs/images/title.png)

*中文为默认语言；`L` 或设置页切换中英，`C` 看署名与授权。*

## 现在能玩到什么

**从头到尾是一局连贯的游戏**：D 级人员 9341 在 173 的测试中遇上收容失效，穿过三区、拉下远程门控、再沿原路爬回地面，四种结局各有一次不同的死法。

| 幕 | 区域 | 内容 |
|---|---|---|
| **I 苏醒** | LCZ 轻收容区 · 13 个区域 | 173 的凝视、手电与眨眼、门禁阶梯、SCP-294、六份文档、两个存档终端 |
| **II 下潜** | HCZ 重收容区 · 17 个区域 | 106 面包屑追踪、966 只闻其声、895 不能直视、372 永远在你背后、914 精加工、三断路器恢复供电 |
| **III 夺权** | EZ 办公区 · 10 个区域 | 049 与它的病人、079 的门禁把戏、只闻其声的 MTF、远程门控与封锁 |
| **IV 回程** | 封锁后的设施 | 灯只有 35%、每扇门都要求三级权限、173 在你熟悉的房间里等你 |

四个结局由「出口 × 撤离方式」决定：被收容 / 被带走 / 被抹除 / 被处决。集齐三份关键文档会额外附上一页事故调查报告。

## 直接运行

```
build\SCP-CB-2D.exe
```

独立可执行文件，107 MB，不需要装引擎。桌面上也有 `SCP-CB 2D` 快捷方式。

从源码跑：

```powershell
D:\software\Godot\4.7.2\Godot_v4.7.2-stable_win64.exe --path .
```

## 机制

| 机制 | 规则 |
|---|---|
| 黑暗与光照 | 全场熄灭，只有顶灯与手电；墙体真实遮挡光线 |
| **"看见"判定** | **手电光锥照到 ∧ 眼睛睁着 ∧ 无遮挡**。环境光不算——站在亮处背对着它，它照样会动 |
| SCP-173 | 没被看见时**瞬移式前进**（每 0.24 秒前移 40px，不滑行）；被看见就冻结；接触即死 |
| 眨眼 | 20 秒强制眨眼 0.35 秒，全黑；可提前按空格把闭眼时机握在手里 |
| 手电电量 | 核心资源，约 5 分钟；`2` 用备用电池回充 |
| 体力 | 冲刺消耗，耗尽只能走 |
| 背包 | `I` 打开，`1-8` 使用 |
| 门禁 | 1/2/3 级钥匙卡；门可开关，但 173 不需要卡，它会撞开 |
| 存档 | 终端存档，死亡回到最近一台；读档不换图 |
| 106 | 不寻路，走你刚才走过的路，速度低于你——它只追得上停下来的人 |

## 操作

| 键 | 动作 |
|---|---|
| `WASD` / 方向键 | 移动 |
| 鼠标 | 手电方向（**逃跑时可以把光留在身后**） |
| `Shift` | 冲刺（耗体力） |
| `空格` | 主动眨眼 |
| `F` | 开关手电 |
| `E` | 交互（开门、拾取、阅读、存档、投币） |
| `I` | 背包 |
| `S` | 设置（音量 / 语言 / 全屏 / 声音字幕） |
| `C` | 署名与授权（标题页） |
| `L` | 切换中英 |
| `Esc` | 暂停 |
| `R` | 重开 |

**声音字幕**默认开启：966 完全不可见、106 靠听定位，这个游戏有一半信息在声音里，所以关键音效会以 `〔石材摩擦声〕` 这样的文字出现在画面上。

## 测试

一个无头套件，29 项，全部通过：

```powershell
powershell -File tools\test.ps1
```

它包含四张关卡的 `--validate`（道具/贴花/文档是否在可走格、门与出口是否连通）、14 条 headless 场景（每个 SCP 一条、转场、存档、结局），以及一条**故意失败的对照**——用来证明这套测试真的会红。

其它自检开关：

```powershell
... --headless -- --validate=res://levels/act2.json   # 单张关卡
... --headless -- --pacing --level=res://levels/act2.json  # 按 beat 估算时长
... --headless -- --audit                              # 素材是否就位
```

## 已知限制

- **回程偏短**：幕 IV 目前是两个房间（约 2 分钟），设计目标是 15–20 分钟。按"先验证再扩"的原则压着没做，等真实试玩数据。
- 文档共 10 份，比原作的几十份少得多；这是刻意的（小屏阅读上限）。
- 英文文案是机翻级再手工润色，英文母语者会觉得生硬。
