## Problem Statement

两幕现在都能玩通，但都在电梯处断掉。幕 III 是整款游戏的**抉择幕**：玩家要拉下远程门控，这个动作同时解决三件事——打开通往 Gate 的权限、让 079 失去门禁控制、把整栋楼变成回程时的死路。

目前引擎里还没有"世界状态会变"这件事：门可以开关，但没有"整栋楼进入封锁"的概念。回程段（幕 IV）完全依赖它。

## Solution

先补**设施状态改写层**：关卡数据里声明若干具名状态（如 `lockdown`），每个状态描述环境光、门锁、SCP 唤醒、播报与目标的变化；触发器的 `state` 动作应用它。然后在其上做幕 III：EZ 办公区、SCP-049、SCP-079、只闻其声的 MTF、远程门控，以及 8 分钟的可验证回程与四个结局。

## User Stories

1. 作为玩家，我想从幕 II 的电梯直接进入 EZ，这样第三幕接得上。
2. 作为玩家，我想 EZ 比 HCZ 干净、明亮、有办公用品，这样气氛从"肮脏"转成"冷漠"。
3. 作为玩家，我想看见 049 在收集尸体并把它们变成"病人"，这样我知道**不要在它附近死**。
4. 作为玩家，我想 049 不主动追我、只是在做它的事，这样它和 106 的压迫感完全不同。
5. 作为玩家，我想 079 通过广播和门禁跟我说话，这样第三幕有个"会说话的对手"。
6. 作为玩家，我想 079 有时帮我开门、有时把我锁在外面，这样我不能完全信它。
7. 作为玩家，我想在 EZ 尽头找到远程门控的闸，这样第三幕有明确目标。
8. 作为玩家，我想拉闸之后听到整栋楼的锁同时弹开，这样我知道自己做了什么。
9. 作为玩家，我想拉闸之后灯变暗、门重新锁上，这样回程不是重复劳动而是新的关卡。
10. 作为玩家，我想在回程中听见远处 MTF 的交火与广播，但从头到尾见不到他们，这样"有人来了"既是希望也是威胁。
11. 作为玩家，我想在回程终点做出选择（拉响撤离广播 / 静默离开），这样结局取决于我。
12. 作为玩家，我想看到四种不同的结局文本，这样重玩有理由。
13. 作为玩家，我想集齐三份关键文档后多看到一页事故调查报告，这样收集有回报。
14. 作为开发者，我想用 JSON 声明一个"封锁状态"并让触发器应用它，这样回程不需要另写一套代码。
15. 作为开发者，我想用一条场景测试证明"拉闸之后门全锁、灯变暗"，这样回程的状态改写不会悄悄失效。

## Implementation Decisions

- **状态层**：关卡数据顶层 `states`，每个状态可含 `lights`（环境光倍率）、`doors`（`lock`）、`wake_scps`、`say`、`objective`。触发器新增 `state` 动作应用它。状态是**幂等**的，重复应用无副作用。
- **门锁语义**：`lock` 会把所有门关闭**并把所需卡等级提升到 3**——回程时玩家已经有 3 级卡，所以门不是打不开，而是**必须重新走过去开**。
- **049**：不追踪。它沿固定路线在尸体之间移动，把附近的尸体转成"病人"；"病人"会缓慢追玩家。玩家死后如果 049 在附近，尸体会被转化——**死亡惩罚在这个区域是双重的**。
- **079**：不是实体，是门禁与广播的**规则层**。它会按脚本开/关特定门、播放语音；有些门它答应开却不开。不做对话树。
- **MTF**：只以声音与光存在（远处交火、走廊尽头的灯与影子），不生成可与玩家交互的实体。这是 ADR 里已定的。
- **远程门控**：一个交互物，触发 `state: lockdown`，然后解锁通往 Gate 的路径（幕 IV 的入口）。
- **回程 8 分钟版**：只走 EZ → HCZ 入口的一段，途中三处状态变化（灯灭、门锁、106 重新活跃）。完整回程等验证后再扩。
- **不改的东西**：不做战斗；看见的判定不变；死亡仍可归因。

## Testing Decisions

- 继续用 `--headless -- --scenario=<name>`，断言只碰可观察状态（状态机、门、环境光、SCP 计数、文档标记）。
- 新增场景：`act3_enter`（从幕 II 电梯落到 EZ）、`act3_049`（尸体被转化、病人出现）、`act3_079`（脚本门在指定时刻开关）、`act3_gate`（拉闸后门全锁、灯变暗）、`act3_mtf`（只播声音、不生成实体）、`act3_endings`（四种触发条件各自到达对应结算）。
- 状态层本身已有 `act2_lockdown` 覆盖（门关闭 + 环境光下降）。

## Out of Scope

- 完整的 15–20 分钟回程。
- 第五结局的结算页面（只保留 `docs_found` 标记，等结局系统做完再接）。
- Gate A / Gate B 的外部场景（用黑场 + 文本表达）。
- 任何战斗或 MTF 实体。

## Further Notes

- 幕 III 的恐怖来自**冷漠**而不是脏：EZ 越干净，049 和 079 越显得不对。
- 回程段的第一条验收标准是"玩家能说出和来时相比哪三件事变了"——说不出来就说明状态改写不够显眼。
