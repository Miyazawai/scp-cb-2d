# ADR 0003：不做战斗系统

- 日期：2026-10-22
- 状态：已接受

## 背景

把 SCP:CB 做成 2D 有两条现成的路：做成有战斗的"收容失效生存动作游戏"（《SCP: Permafrost》已经占了这条路），或者做成原作那样"完全没有还手能力"的逃逸游戏。

原作是后者。玩家是 D 级人员，没有武器、没有血量、没有成长；被 173、049、106 碰到基本就是死。它的恐怖不来自"打不打得过"，而来自"你根本没法打"。

## 决策

**永久不做战斗系统**：没有攻击、格挡、闪避、血量条、伤害数值、经验或技能树。玩家的全部手段是移动、躲藏、开关灯、跑，以及利用视野。

## 理由

- 恐怖来自无力感。一旦给玩家攻击手段，威胁就降级成"敌人"，紧张感变成资源管理。
- 差异化：直接有战斗的 2D SCP 游戏已经存在，而"只看不打的俯视 SCP"还是空的。
- 它把设计压力集中到一个变量上——**能不能看见**。所有系统（手电、眨眼、门禁、声音）都可以围绕这一个变量设计，而不是围绕伤害公式。

## 后果

- 死亡必须是瞬时的或接近瞬时的（接触即死、被抓即死），因此"逃脱窗口"比"血量"重要：玩家的容错来自"还有没有退路"，而不是"还剩多少血"。
- 关卡设计必须保证每个危险房间都有至少一条可退的路，否则无战斗力会变成无解。
- 所有数值都只能投在**信息与移动**上（视野半径、电量、脚步声、门的开合速度），不能投在伤害上。
- 未来任何"加个武器/加个血条"的提案，都需要先推翻这份 ADR。
