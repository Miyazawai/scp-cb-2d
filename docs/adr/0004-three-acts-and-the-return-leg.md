# ADR 0004：三幕 + 强制回程作为结构主干

- 日期：2026-10-22
- 状态：已接受（待用户最终确认幕 IV 长度）

## 背景

把 SCP:CB 做成 2D 之后，自由探索型的设施会散掉：玩家在黑暗里没有方向感，随机生成又会让他们永远在"新地方"，恐怖从"熟悉的东西在变"退化成"一堆陌生的走廊"。

需要一条能同时提供**方向感**、**节奏控制**和**高潮**的结构主干。

## 决策

采用**三幕纵向推进 + 强制回程**：

1. **幕 I LCZ**（教学／惊慌）
2. **幕 II HCZ**（主体／疲惫与偏执）
3. **幕 III EZ**（抉择／冷）
4. **幕 IV 回程**（高潮／熟悉被改写）

玩家在幕 III 拉下"远程门控"闸门，获得通往 Gate 的权限，代价是**灯全灭、所有电子锁重置**，然后必须沿原路走回去。

## 理由

- 纵向推进给"越走越深"的方向感，这是恐怖最基本的地形学。
- 回程把玩家已经建立的**空间记忆**变成叙事资产：来时的每一条退路都要重新验证。这是唯一一种"不需要新增美术量"就能制造高潮的手段。
- 门控闸门同时解决了叙事动机（为什么要往回走）与系统代价（为什么回程变难），一个开关做两件事。
- 自由顺序会让玩家在错误的分区里耗尽资源，那是不可归因死亡，违反 `可归因死亡` 的定义。

## 后果

- 必须实现**设施状态改写**：门锁状态、灯具开关、威胁重定位、部分通道塌陷。这是一套独立的状态层，不是简单的"再走一次"。
- 回程段落有"重复劳动"的风险。若玩家测试显示它读起来像重复，幕 IV 应缩短为"只走最后一段"而不是砍掉。
- 关卡编辑器（M2 前必须做）要支持"同一张图的两种状态"。
- 存档点分布必须保证玩家在回程中至少有一个呼吸点，否则回程会变成纯粹的惩罚。
