# ADR 0001：俯视 2D + 光照遮蔽作为一等机制

- 日期：2026-10-22
- 状态：已接受

## 背景

SCP:CB 是 3D 第一人称，它的恐惧来自"你在一栋看不全的走廊网络里，身后有东西在动"。把它做成 2D 至少有五种形态：俯视 tile、横版平台、伪 3D raycasting、2.5D 侧视，以及各自的变体。

这个选择几乎不可逆：它同时决定了美术规格、操作方式、AI 与关卡工具链、"看不清"如何实现。所以宁可在这里多花时间。

## 决策

采用**俯视 tile-based**，并把"看不见"做成系统级机制（光照遮蔽／视野范围），而不是画面滤镜。

## 理由

- 原作的空间是一张走廊网络。迷路、听声辨位、转身发现 173 移动过——这些体验来自"你在图里，但看不全"，而不是来自第一人称视角本身。
- 横版会把"逃出走廊"变成"跳过障碍物"，恐怖降级为操作挑战。
- 伪 3D raycasting 等于用 2D 重做第一人称，要同时和视角、碰撞、遮挡三件事搏斗，投入产出比最差。
- 俯视网格能一比一保留原作的门、走廊、房间拓扑，程序化生成的思路也可以直接借鉴原作（见 `docs/research/map-generation-spec.md`）。

## 后果

- 美术只需要俯视 tileset 与 4 向角色，不需要 3D 模型和第一人称手部动画。
- 必须自建"看不见的东西仍在行动"的模拟：视野锥之外的实体继续按自己的规则移动。
- 原作的经典惊吓（转身 face-to-face）要改写成"视野边缘"与"声音"两条通道。
- 玩家能记住地图空间，因此随机生成必须保证每局的拓扑差异足够大，否则恐怖感会在第二局消失。
