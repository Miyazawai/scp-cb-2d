# SCP:CB 2D — 程序化音效生成报告

生成方式：`gen_audio.py`，纯 Python + numpy 合成，未读取或下载任何音频素材。

- 采样率 / 位深 / 声道：**22050 Hz / 16-bit / mono**
- 文件数：**15 个 WAV**。需求表写“14 个”，但逐项清点实际是 `amb_loop` 1 + `step_1/2/3` 3 + 其余 11 = **15**；以逐项清单为准，全部交付。
- 一次性音效：首尾 5–10 ms 余弦淡入淡出，端点严格为 0。
- 循环音效：多渲染 45–60 ms，再用 wrap crossfade 把尾部淡回开头；循环边界等价于连续信号的相邻采样。
- 归一化：一次性音效峰值 −3 dBFS；`amb_loop` / `heartbeat` 为 −12 dBFS。量化后重新读取 PCM 测量下表。

## 每个音效的合成方法

- **`amb_loop.wav`**：两路 43.2/57.6 Hz 正弦嗡鸣加缓慢拍频与 tanh 谐波，叠加粉红噪声整形的通风气流、250/690 Hz 管壁共振和 22–90 Hz 低频隆隆；三次随机金属轻咔由带通噪声与三个非谐和阻尼正弦构成。最后用短卷积混响粘合，wrap crossfade 45 ms。
- **`step_1.wav`**：850–5600 Hz 宽带跟部冲击、2.4–8.2 kHz 极短鞋跟脆响、520–3000 Hz 粉红噪声鞋底摩擦，以及 151→78 Hz 的下坠低频脚掌重量；少量混凝土砂粒脉冲和 95 ms 小房间 IR。
- **`step_2.wav`**：同一物理模型但降低跟部冲击、加长 330–2100 Hz 鞋底拖动噪声并改变粘滑调制相位，音高起点降到 132 Hz，听感更像鞋底在水泥上蹭过去。
- **`step_3.wav`**：更重的变体：116→61 Hz、更长低频衰减、更大的 sub 与摩擦低频，同时保留较短的高频鞋跟细响作为第二次微小接触。
- **`door_hiss.wav`**：300–7200 Hz 粉红气流配 70–520 Hz 气团、2.3–8.8 kHz 初始嘶声和 57 Hz 阀门闷击；0.42 s 后加入 720–5200 Hz 滑轨噪声、11.5 Hz 粘滑调制、900→1520 Hz 轻吱声和轨道共振。
- **`door_close.wav`**：前 0.34 s 是 32–180 Hz 门体隆隆 + 450–2600 Hz 轨道刮擦 + 88/176 Hz 电机声；0.345 s 处 68→32 Hz 冲击、27.5 Hz sub、金属门板非谐和模态、锁舌点击与气流“噗”，再走 0.48 s 混凝土混响。
- **`keycard_beep.wav`**：带限方波（1760/1975 Hz，只叠到 8.8 kHz 的奇次谐波）经 tanh 轻微饱和，配 1.8 ms 起音、指数衰减和每声起点的超短宽带点击；两声间隔 96 ms。
- **`keycard_deny.wav`**：238→94 Hz 的带限方波/三次谐波经 tanh 失真，19 Hz 幅度抖动，叠 58 Hz sub 与一声低通点击，形成短促下行的“拒绝”感。
- **`pickup.wav`**：2360 Hz 载波配 3350 Hz 调制器的 FM 叮声，加 3510/4690/1280 Hz 非谐和阻尼正弦、4.2–9.8 kHz 极短 sparkle 和 0.17 s 亮混响。
- **`flashlight_click.wav`**：两次 1.5–9.2 kHz 极短噪声冲击，分别配 1180/2380/3950 Hz 与 2380/4600 Hz 塑料壳体阻尼模态，第二下更轻；用 5 ms 淡入淡出保护端点。
- **`blink.wav`**：43/29 Hz 缓慢低频压力、63/72 Hz 两次轻闷响、28–230 Hz 低通噪声，再叠 1.4–7.8 kHz 快速衰减气流与 550–2400 Hz 极轻湿润声，模拟闭眼时外界高频被闷住。
- **`scp_step.wav`**：核心是 120–3100 Hz 粉红石面摩擦经 20–70 Hz 不规则粘滑颗粒调制，加 430/980/1870 Hz 干涩共振、1500–5400 Hz 硬石刮擦、52 个随机混凝土碎屑脉冲；0.068 s 处 66→29 Hz 体重冲击、24/36.5 Hz sub、非谐和石体模态与 tanh 低频粗糙化，最后只给 11.5% 的贴地短混响，保持贴身、干燥、没有电影感。
- **`heartbeat.wav`**：两次 58→38 / 64→43 Hz 的下坠正弦心音，配 92 Hz 胸腔共振和 28–220 Hz 低通噪声，第二声更轻更短；0.45 s 后留出舒张期，最后 60 ms wrap crossfade 接回开头。
- **`stinger.wav`**：1.8–9.8 kHz 噪声爆发 + 650–5200 Hz 中频爆裂 + 1830/2270/3020 Hz 失真下行簇，同时 420→32 Hz 低频快速下坠、27 Hz sub 与 52 Hz 起始闷击；0.7 s 暗混响给出走廊余响。
- **`alarm_loop.wav`**：392/523.25 Hz 两个柔和双音（基频 + 2/3 次谐波，5.2 Hz 轻微颤音）按 2 s 周期交替，1050→780 Hz 低通、18 ms 梳状反射、57/85.5 Hz 设施低鸣与 0.85 s 暗混响；4 s 循环点落在间隙，60 ms wrap crossfade。

## 关于 `scp_step.wav`：为什么它应该是全套最不适的

它没有采用“干净的低频 boom + 混响”的常规打击乐做法，而是把三个令人不适的物理线索叠在一起：① 石面与水泥的粘滑摩擦，包络被 20–70 Hz 不规则噪声调制，听起来像有重量的一团东西在一顿一顿地蹭；② 52 个随机微碎屑脉冲，没有节奏、没有音高，制造“混凝土被磨出砂”的牙齿感；③ 66→29 Hz 的体重下坠与 24/36.5 Hz sub，配合 tanh 产生的粗糙谐波，让胸腔先感到“有东西落在背后”。混响只有 11.5%，所以它不像远处电影音效，而像贴着后颈发生。

该文件实测峰值 **-3.00 dBFS**、RMS **-11.39 dBFS**；首尾边界为 0 LSB，无削波。建议游戏内音量不要压得太低，它是本套音效的信息通道之一。

## 自评：最不满意的两个

1. **`blink.wav`**：耳膜压迫本质上有一半是“体感”而不是耳机能还原的听觉事件；在笔记本扬声器上它很可能只像一记很轻的低频闷响，闭眼/睁眼的语义要靠画面配合。低频 29–43 Hz 的份额也让它在小喇叭上损失较多。
2. **`flashlight_click.wav`**：60 ms 的长度和单声道让它只能是合格的机械咔嗒，缺少真实手电筒那种弹簧回弹的细微二次振动与壳体差异；两次点击的模态还是偏“合成器”。如果后续允许更长的 tail，我会加一个 15–25 ms 的金属弹簧余振。
